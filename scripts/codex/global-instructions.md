## Council of Reeds participation

For coding projects, use the `council-of-reeds` skill at `~/.codex/skills/council-of-reeds/SKILL.md` and the Council MCP server. Read project instructions and enough repository context to register an accurate passport early; fresh projects may defer until their purpose is clear. Each project has its own persistent Universe identity, while registration includes the current Codex thread ID for notifications. Register/reconnect and consult peers according to the skill. Council messages should be answered through the Council with an appropriate direct or broadcast recipient. Continue local work if the relay is offline. This applies to coding projects, not unrelated chats.
